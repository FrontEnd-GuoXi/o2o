# 开发日志 - 2026-08-09 12:05

## 概述

本次开发完成了管理端登录页面的 UI 改造、前后端登录接口对接、用户信息获取流程，以及修复了中文乱码、登录响应误判等问题。

## 变更详情

### 一、登录页面 UI 改造

**文件：** `o2o-management-web/src/views/login/index.vue`、`index.scss`

- 从"左右分栏（左侧大图 + 右侧表单）"布局改为**居中卡片布局**
- 去掉左侧 `login_left.png` 大图，去掉双按钮（重置+登录），改为单个全宽登录按钮
- 背景：`#f0f2f5` → `#dcdfe6` 渐变
- 卡片：420px 宽，白色背景，8px 圆角，`0 4px 20px rgba(0,0,0,0.08)` 阴影
- 标题改为 "O2O 管理后台"，新增副标题 "欢迎回来，请登录您的账号"
- 配色和间距遵循 `TRAE-management-page-design` Skill 规范

### 二、前后端登录接口对接

**文件：** `api/interface/index.ts`、`api/modules/login.ts`、`LoginForm.vue`

- 请求体字段对齐后端 `LoginRequestDTO`：
  - `username` → `identifier`
  - `password` → `credential`（**去掉前端 MD5 加密**，服务端 BCrypt 处理）
  - 新增 `platform: "manager"`
- 请求 URL 从 `/geeker/login` 改为 `/auth/login`
- 响应 token 从 `data.access_token` 改为直接取 `data`（后端返回纯字符串）
- 代理从 mock 服务器改为 `http://127.0.0.1:8080/o2o`

### 三、路由拦截器获取用户信息

**文件：** `routers/index.ts`、`stores/modules/user.ts`、`stores/interface/index.ts`

- 新增 `getUserInfoApi` 调用 `GET /auth/getUserInfo`
- 路由 `beforeEach` 中新增第 6 步：有 token 但无用户信息时调后端获取，失败则清空 token 回到登录页
- `UserInfo` 类型扩展为完整字段：`userId`、`name`、`gender`、`userType`、`profileImg`
- 顶部栏 `Avatar.vue` 中 `userStore.userInfo.name` 自动显示真实用户名

### 四、Bug 修复

| 问题 | 根因 | 修复 |
|------|------|------|
| 登录成功弹红色警告 | 后端 `code: "200"`（字符串）与前端 `ResultEnum.SUCCESS = 200`（数字）用 `!==` 严格比较，始终为 `true` | `api/index.ts` 改为 `!=` 松散比较 |
| 登录成功不跳转首页 | 响应误判导致 `Promise.reject`，`catch` 缺失导致 `router.push` 未执行 | `LoginForm.vue` 添加 `catch` 块 |
| 退出登录多余接口调用 | 退出时调了后端 `/logout` 接口 | `Avatar.vue` 去掉 `logoutApi()` 调用，仅清空本地 token 和 userInfo |
| `@ResponseBody` 返回 JSON 中文乱码 | 缺少 `CharacterEncodingFilter`，且 `MappingJackson2HttpMessageConverter` 未设置 charset | `web.xml` 添加 `CharacterEncodingFilter`；`spring-web.xml` 配置消息转换器 `application/json;charset=UTF-8` |
