# 开发日志 - 2026-08-15

## 概述

本次开发主要完成了**店铺管理列表页面**的前后端功能，同时引入了 **PageHelper 分页插件**，并修复了**中文乱码**问题。

---

## 一、后端改动

### 1. 引入 PageHelper 分页插件

- **pom.xml**：添加 `com.github.pagehelper:pagehelper:5.3.2` 依赖
- **spring-dao.xml**：在 `SqlSessionFactoryBean` 中配置 `PageInterceptor` 插件，设置 MySQL 方言，开启 `reasonable`、`supportMethodsArguments` 等参数

### 2. 新增 PageUtils 工具类

- 路径：`src/main/java/com/o2o/util/PageUtils.java`
- 提供 `PageInfo<Entity>` → `PageInfo<VO>` 的转换方法，保留分页属性（total、pageNum、pageSize 等），仅替换 list 内容

### 3. AuthServiceImpl 优化

- 补充 `userTypeName` 字段映射（通过 `UserTypeEnum.fromCode().getDesc()` 获取中文描述）
- 清理未使用的 `UserContextHolder` import

### 4. 修复中文乱码

- **logback.xml**：CONSOLE appender 添加 `<charset>UTF-8</charset>`，解决控制台日志中文乱码
- **pom.xml**：maven-compiler-plugin 添加 `<encoding>UTF-8</encoding>`，解决 Maven 编译时源码中文乱码

## 三、技术决策

| 决策项 | 选择 | 原因 |
|--------|------|------|
| 分页方案 | PageHelper | 比 MyBatis-Plus 更轻量，无需改 DAO 接口和实体类，只需加依赖 + 配置拦截器即可 |
| 分页 VO 转换 | PageUtils 工具类 | 避免手动逐字段拷贝分页属性，`BeanUtils.copyProperties` 自动处理 |
| 编码修复 | UTF-8 统一配置 | Maven 编译 + Logback 输出均设置为 UTF-8，彻底解决中文乱码 |
