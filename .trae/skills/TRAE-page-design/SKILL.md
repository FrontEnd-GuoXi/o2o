| 间距 | 用途 |
|---|---|
| `8px` | 小元素间距（图标与文字） |
| `12px` | 卡片内边距、元素间距、section 底部间距 |

## 五、Vant 组件使用规范

以上是项目中已使用和推荐使用的 Vant 组件及其样式约定：

| 组件 | 用法 & 样式约定 |
|---|---|
| **Icon** | 用于导航、操作图标，配合 `color` 属性使用品牌色 |
| **Swipe** | Banner 轮播，高度 `160px`~`200px`，指示器 `bottom: 6px` |
| **Image** | 商品/店铺图片，`object-fit: cover`，懒加载 |
| **Toast** | 轻提示，用于操作反馈 |
| **Popup** | 弹窗，用于规格选择、筛选等 |
| **Form / Field** | 表单输入，输入框 `border-radius: 8px` |
| **Button** | 操作按钮，`border-radius: 8px`，主按钮品牌色 |
| **Card** | 商品卡片，左侧图片 `80px`，右侧信息 |
| **Checkbox** | 购物车选择，配合 `icon-size` |
| **SubmitBar** | 底部结算栏，购物车页使用 |
| **Empty** | 空状态，配友好提示文案 |
| **Tag** | 标签，用于分类、热门标记 |
| **Cell / CellGroup** | 列表项，用于规格选择、设置项 |
| **NavBar** | 顶部导航，`position: fixed`，`z-index: 100` |
| **Tab / Tabs** | 分类切换，配合 `sticky` 吸顶 |
| **Skeleton** | 骨架屏，首屏加载时使用 |
| **PullRefresh** | 下拉刷新 |
| **List** | 上拉加载更多 |

## 七、细节规范

### 图片处理
- 所有图片使用 `object-fit: cover` + `width: 100%` + `height: 100%`
- 图片容器设置固定高度，`overflow: hidden`
- 大图 hover 效果：`transform: scale(1.05)` + `transition: 0.3s ease`

### 卡片 hover 效果
```css
.card:hover {
  transform: translateY(-2px);
  box-shadow: 0 4px 16px 0 rgba(0, 0, 0, 0.1);
}
```

### 文本溢出
- 单行省略：`overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`
- 多行省略：`display: -webkit-box; -webkit-line-clamp: 2; -webkit-box-orient: vertical; overflow: hidden;`

### 交互反馈
- 按钮点击：`:active { opacity: 0.9; }` 或 `transform: scale(0.9)`
- 输入框 focus：`border-color: #409eff; box-shadow: 0 0 0 2px rgba(64,158,255,0.1)`

### 空状态
- 使用 Vant `Empty` 组件
- 空购物车：提示文案 + "去逛逛" 按钮跳转首页

---

## 八、响应式适配

- 使用 `px` 编写样式，`postcss-px-to-viewport` 自动转 `vw`
- 移动端适配断点：`@media (max-width: 768px)`
- 图片按设计稿 375px 宽度编写 px 值
- 字体最小 `12px`，按钮最小点击区域 `44px × 44px`

## 九、输出格式

当用户要求设计页面时，按以下顺序输出：

1. **页面布局结构图**（ASCII 示意图）
2. **关键 Vant 组件选型**（列出用到的组件及用途）
3. **配色方案**（注明使用的颜色值，与项目保持一致）
4. **完整代码**（按项目规范：`index.vue` + `style.css` + `useXxx.ts`）
